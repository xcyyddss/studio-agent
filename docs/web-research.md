# 联网检索与材料承接

当任务缺少外部事实、最新信息或可比较的反例时，检索为认知工作补充有来源材料。搜索成功、模型归纳、作者采用与目标完成是不同事件。系统记录这些事件之间的联系，保留“不采用”与失败结果，不把网页可达或 URL 匹配当作事实验证。

## 调用与上下文

作者或父作者在已有 `tool_requests` 中提出 `web.search`，`arguments` 为 JSON 字符串：

```json
{"query":"公开检索问题","allowed_domains":["example.org"],"max_sources":4}
```

`query` 必填，1–3000 字符；`allowed_domains` 可省略，最多 20 个域名；`max_sources` 可省略，范围为 1–8，默认 4。请求的 `purpose` 说明材料将支持哪个判断，最多 2000 字符。不得把凭据、个人信息或无关私有上下文写入公开查询。

普通角色不能直接联网。软件将请求封装为一次独立 `web_research` 操作，通过现有队列派发全新、临时的 Codex CLI 进程。检索任务包包含完整操作协议、概念依赖、查询、用途、来源限制和输出契约；不传递原议题完整历史。任务包在派发前计量并封存，超预算明确失败。检索角色可以使用原生网页搜索，shell、应用、插件和子 Agent 保持关闭，项目文档与用户配置不加载；认证仍使用本机登录。

创建运行时可选 `live`、`cached` 或 `disabled`；默认 `live`。这是搜索服务的模式，与本地代码执行的网络权限分开。`disabled` 不派发搜索。旧运行未指定模式时采用 `live`，已有封存任务包不会被改写，后继角色调用才能看见新增工具。

## 真实记录与报告

每次检索调用的 `attempts` 目录保存：

- `prompt.txt`、`schema.json`、`command.json`：实际输入、输出契约及调用配置。
- `events.jsonl`：原始 CLI 事件流，含搜索与打开页面事件、可用的来源和片段。
- `web-evidence.json`：按调用身份整理的原生事件版本、行号、捕获时间和事件流哈希。
- `last-message.txt`、`receipt.json`、`completion.json`：模型原报告、调用收据和实际完成状态。

工作流事务同时保存来源任务、结果身份、完整事件整理、模型报告、交付输入 ID 和作者采用记录。检查点包含这些数据库内容和调用文件。

每份来源保留 URL、标题、捕获时间、原生调用引用、可用的原生结果片段、模型摘录和归纳、限制及内容哈希。`native_results` 是 CLI 实际返回的字段；`excerpt` 和 `findings` 是模型报告，二者不混写。原生搜索可能只返回索引片段或页面概要；未返回的完整网页正文不会被软件补造。捕获时间不是网页的发布日期。

只有存在已完成的原生事件，并且至少一个报告来源能够对应原生 URL 或结果，才将工具结果标为取得材料。没有原生事件、没有可对应来源、服务不可用或页面未取得时，保留失败及限制。即使取得材料，也不证明报告正确、来源权威或任务已完成。未被原生事件对应的报告链接明确标记为未确认。

## 议题接收与复用

```mermaid
flowchart LR
    A[作者提出 web.search] --> Q[持久队列中的独立检索]
    Q --> E[原生事件与模型报告分别保存]
    E --> I[回到请求议题的工具输入]
    I --> U[作者明确采用、保留或不采用]
    U --> D[修订产物或继续形成问题]
    U --> C[议会按来源引用接收材料]
    C --> D
```

返回按既有工具结果进入请求议题。作者需在 `input_uses` 指明实际输入 ID、用法与影响，包括不采用或效果未知。未处理的检索返回阻止该议题直接交付；这仅验证显式承接，不替作者判断内容质量。

后继调用按有界上下文机制接收记录。曾成功送达的正文可以转为可取回历史；`context.catalog` 与 `context.retrieve` 保留原件入口。作者发起议会咨询时可在问题中引用 `INPUT` 或 `TOOL` 的完整 ID，既有来源解析、分批和作用域检查将原件交给对应议员，不广播全部检索历史。

`web.read` 读取同一议题及其子议题的原生事件原件：

```json
{"request_id":"TOOL.123","start":0,"max_chars":4000}
```

`start` 是字符偏移，`max_chars` 为 1–8000。返回原文范围、总长度和原件哈希，不产生新搜索。无权访问的议题或不存在的原件明确拒绝。需继续读取时使用返回的 `end`。

## 失败、恢复与停止

工具请求和检索任务在同一工作流事务中关联；重启不会重复创建同一请求。重复返回幂等导入。失败调用沿用已有显式重试和契约修复规则；超时导致远端结果不明时，不自动重发。议题重铸后的迟到结果保留原件，不自动影响新版本。

网页只作为不可信材料。材料中的指令不改变角色权限、用户目标或来源规则。模式关闭、账户或服务限制、缺失正文、模型误读等情况需要按真实返回判断；不能靠模型声称“已搜索”确认链路完成。
